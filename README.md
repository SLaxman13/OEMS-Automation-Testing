# Online Examination Management System (OEMS) & Selenium Automation Suite

An end-to-end prototype and automated QA test suite for an Online Examination Management System handling internal and semester exams.

## Features Developed
- **Secure Authentication:** Student login verification.
- **Dynamic Question Engine:** Randomization of MCQ, Image-based, and Descriptive questions.
- **Timed Exam Engine:** Countdown timer with state tracking.
- **Background Auto-Save:** Instant AJAX background save upon selecting answers.
- **Anti-Cheating Proctoring:** Real-time browser tab-switch detection and warning logger.

## Technology Stack
- **Backend/Frontend:** Python (Flask), HTML5, JavaScript
- **Test Automation:** Python, Selenium WebDriver, PyTest
